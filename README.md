# Standard ML of Jersey City

WIP implementation of <a href="https://smlnj.org/sml97.html">SML '97</a>

Standard ML of Jersey City is (going to be) an independent implementation of
the Standard ML programming langauge. The name is inspired (but unafilliated with)
the <a href="https://smlnj.org/smlnj.html">Standard ML of New Jersey</a> compiler.

## No AI Training Promise
I do not consent to this repository, its code, documentation, or associated
assets being scraped, collected, or used to train artificial intelligence,
machine learning, or large language models (LLMs)
